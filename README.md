# token家政婦 — Hackathon showcase

A standalone Hermes Plugin that prepares source-grounded 5W1H task cards. This is a **public showcase repository** with an independent history; it is not a mirror of the private development repository.

The installable candidate and its documentation are proposed in the open pull request. The `main` branch is a lightweight review base, not the install target.

**License:** No open-source license has been granted or selected yet. Public visibility does not grant reuse rights; contact the owner before redistribution or adaptation.

**Status:** Work in progress. A structurally `ready` card is advisory and never grants authority to execute an action. End-to-end token savings and live Discord flow are not certified.
